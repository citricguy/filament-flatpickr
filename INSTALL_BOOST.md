# Installing Laravel Boost (development)

This project includes helper composer scripts and Testbench wrappers to make running Laravel Boost simple during plugin development.

> This document records the exact steps used to set up Boost in this package repository so you can reproduce them later.

## Quick commands

- Install Boost as a dev dependency:

```bash
composer require --dev laravel/boost
```

- Run the helper wrapper to install Boost's guidelines and MCP server (uses Testbench):

```bash
composer boost:install
```

- Start the local MCP server (recommended for editor integration):

```bash
composer boost:mcp
# or directly
vendor/bin/testbench boost:mcp
```

- Update Boost guidelines:

```bash
composer boost:update
```

## What happened when we ran `boost:install` here (notes & troubleshooting)

1. When first running `vendor/bin/testbench boost:install -n`, Boost failed with:

```
SQLSTATE[HY000]: General error: 1 no such table: cache
```

This is because Boost uses the cache table and the Testbench in-memory DB didn't contain the table yet.

2. Steps taken to fix this in this repository:

```bash
# create a persistent sqlite DB for package development
vendor/bin/testbench package:create-sqlite-db --force

# create the cache table migration
vendor/bin/testbench cache:table

# run migrations (on the created sqlite DB)
vendor/bin/testbench migrate -n

# rerun Boost install (non-interactive)
vendor/bin/testbench boost:install -n
```

3. After successful installation Boost created guideline & MCP config files and set up MCP servers for supported agents.

Files you will notice:

- `database/database.sqlite` — persistent SQLite DB file used by Testbench. (Add to .gitignore unless you want to commit it.)
- `AGENTS.md`, `GEMINI.md`, `.gemini/settings.json`, others — guideline & agent files generated by Boost

## How to start the MCP server from this repo

- Using composer helper:

```bash
composer boost:mcp
```

- Or use Testbench directly (recommended if you want to see full output):

```bash
vendor/bin/testbench boost:mcp
```

In VS Code:
- Open the Command Palette → "MCP: List Servers" → select `laravel-boost` → Start server

## Notes & recommendations

- Boost requires an Artisan/Laravel environment. In a package repo we use `orchestra/testbench` as a lightweight app context.
- If you prefer not to prepare a persistent DB in the package repo, you can run Boost from a small local Laravel app and point your editor there.
- Consider adding `database/database.sqlite` and generated transient files to `.gitignore` (I added them below).
